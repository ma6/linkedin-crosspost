# Contributing

Short version: **please don't — and use it freely anyway.**

## No support

This plugin is GPL-2.0-or-later. Run it, change it, redistribute it — the GPL
asks you to pass the same freedoms on, and then you are done. Nothing is owed
in return, and nothing is owed to you: no support, no answers, no fixes on a
schedule, no compatibility promise to anyone who is not paying for one.

That is not unfriendliness. A side project that quietly acquires obligations to
strangers stops being maintainable by one person, and this one is maintained by
one person on purpose.

## Issues are the maintainer's working notes

Every change here starts as a GitHub Issue before it is built, because a commit
records what changed and only a ticket records what was asked for. Those issues
are one person's own thread, not a public queue.

**Issue creation is limited to repository collaborators** (GitHub interaction
limits). That is not a judgement of anything you might report — it is that
triage is work this project does not take on. If something here is broken, you
have the source and the licence to fix it in your own copy, which is faster
than waiting on anyone.

## Pull requests are not accepted

Not a review-quality question. Merging someone else's change means keeping a
second person's reasoning alive in a repository built on the premise that the
reasoning is written down and stays true (`AGENTS.md`, the commit history).
That is a cost this project is not set up to carry.

## Forking

That is what the licence is for. Fork it, ship it, change whatever you like —
keep the GPL notice and the freedoms attached to it.

## Security

If you find something with security consequences, use GitHub's **private
vulnerability reporting** — the "Report a vulnerability" button under the
repository's **Security** tab. That channel is open to everyone even though
issue creation is not. See "No support" for what a report does and does not
promise.
